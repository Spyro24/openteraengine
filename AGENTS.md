# AGENTS.md: guide for AI agents and contributors

Openteraengine is a python 2d terraria like engine with a game, its higly modable trough the /res path

## 1. For Agents

* Only read the stuff from section 2 that you need to complete your task
* Never touch the /res path
* Create always a new branch for the task
* always use camelCase
* Never use obfuscation

## 2. Orientation

| Read | for |
|---|---|
| `helper/perlin` | perlin noise functions (for 1d and 2d perlin noise) |
| `engine/world` | contains the world stuff like chuncks and the world system |
| `engine/game` | contains the game stuff like camera (it dosnt contain the game) |
